# 图片内容描述

这是一张尺寸为 1920×879 的“千问AI平台”网页首页截图，整体为浅灰白色背景，左侧是浅色侧边栏，右侧是首页仪表盘。截图中没有打开任何弹窗；因此没有可描述的弹窗文字或弹窗按钮。

## 顶部区域

- 左上角是蓝色抽象标志，旁边写着“千问AI平台”。
- 右上角横向导航依次为“体验”“模型”“应用”（后面有下拉箭头）、“Token Plan”“文档”“工作台”。最右侧是蓝紫渐变的圆形头像，里面有字母“N”。

## 左侧导航栏

侧边栏中的菜单从上到下为：

1. “首页”，左侧有主页图标，当前处于选中状态，背景为灰色圆角块。
2. “模型体验”，左侧是闪光图标，右侧有渐变色“Hot”标签和一个外部链接图标。
3. “用量分析”，左侧是分析图标，右侧是向上的折叠箭头；该菜单已展开，子项为“用量”和“日志”。
4. “账单”，左侧是文件图标，右侧是向上的折叠箭头；该菜单已展开，子项依次为“按量付费”“Token Plan”“发票管理”。
5. “模型生成”。
6. “API Keys”。
7. “设置”，右侧是向上的折叠箭头；该菜单已展开，子项为“账号”。

侧边栏最底部还可见一个带门形/退出含义的图标。各菜单左侧均配有线框风格图标。
